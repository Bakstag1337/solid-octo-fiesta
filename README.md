# ⚡ Desktop System Monitor

Красивый и легкий системный монитор для Linux, который показывает информацию о нагрузке системы прямо на вашем рабочем столе!

![Python](https://img.shields.io/badge/python-3.6+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Linux-lightgrey.svg)

## ✨ Возможности

- 💻 **CPU** - процент загрузки, количество ядер, частота
- 🧠 **RAM** - использование оперативной памяти
- 💾 **Disk** - использование дискового пространства
- 🌐 **Network** - скорость загрузки/выгрузки в реальном времени
- 🌡️ **Temperature** - температура CPU (если доступно)
- ⏱️ **Uptime** - время работы системы

## 🎨 Особенности

- Прозрачное окно, всегда поверх других приложений
- Красивый темный дизайн с цветными индикаторами
- Цветовая кодировка нагрузки:
  - 🟢 Зеленый: низкая нагрузка (< 50%)
  - 🟡 Оранжевый: средняя нагрузка (50-80%)
  - 🔴 Красный: высокая нагрузка (> 80%)
- Можно перетаскивать окно мышкой
- Обновление данных каждую секунду
- Минимальное потребление ресурсов (~20-30 MB RAM)

## 📋 Требования

- Python 3.6 или выше
- Linux (любой дистрибутив)
- Tkinter (обычно уже установлен)
- psutil

## 💡 Использование

Запустите программу командой:

```bash
./src/sysmon.py
```

Или:

```bash
python3 src/sysmon.py
```

### Автозапуск при входе в систему

#### GNOME / Ubuntu

1. Откройте "Автозапуск приложений"
2. Добавьте новую программу:
   - Название: System Monitor
   - Команда: `/полный/путь/к/solid-octo-fiesta/src/sysmon.py`
   - Комментарий: Desktop System Monitor

#### KDE Plasma

1. Откройте "Настройки системы" → "Запуск и завершение" → "Автозапуск"
2. Добавьте скрипт запуска

#### Для всех DE (через .desktop файл)

Создайте файл `~/.config/autostart/sysmon.desktop`:

```desktop
[Desktop Entry]
Type=Application
Name=System Monitor
Exec=/полный/путь/к/solid-octo-fiesta/src/sysmon.py
Hidden=false
NoDisplay=false
X-GNOME-Autostart-enabled=true
```

## 🎮 Управление

- **Перетаскивание**: Нажмите и тащите окно для изменения положения
- **Закрыть**: Нажмите кнопку закрытия окна или `Ctrl+C` в терминале

## 🔧 Настройка

Вы можете изменить параметры в файле `src/sysmon.py`:

```python
self.update_interval = 1000  # Интервал обновления в миллисекундах
self.attributes('-alpha', 0.9)  # Прозрачность окна (0.0 - 1.0)
self.geometry("350x450+50+50")  # Размер и позиция окна
```

### Цвета темы

```python
self.bg_color = "#1e1e1e"  # Цвет фона
self.fg_color = "#ffffff"  # Цвет текста
self.accent_color = "#0078d4"  # Акцентный цвет
```

## 🐛 Устранение неполадок

### Tkinter не найден

На некоторых системах нужно установить tkinter отдельно:

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**Fedora:**
```bash
sudo dnf install python3-tkinter
```

**Arch Linux:**
```bash
sudo pacman -S tk
```

### Температура не отображается

Температурные датчики не всегда доступны в виртуальных машинах или на некоторых системах. Это нормально - программа будет работать без этого раздела.

## 📸 Скриншоты

*(После запуска программы вы увидите красивое окно с реалтайм мониторингом)*

Основные метрики отображаются с цветными прогресс-барами и подробной информацией:
- CPU показывает процент загрузки, количество ядер и текущую частоту
- RAM отображает использованную и общую память в GB
- Disk показывает занятое место на корневом разделе
- Network отображает текущую скорость upload/download
- Temperature показывает температуру процессора (если датчики доступны)
- Uptime показывает время работы системы

Все метрики обновляются каждую секунду и меняют цвет в зависимости от нагрузки!
