# 📈 Backtesting Platform - Web Version

Статический веб-сайт для тестирования дейтрейдинговых стратегий.

## 🌐 Live Demo

**Сайт доступен по адресу:** [https://bakstag1337.github.io/solid-octo-fiesta/](https://bakstag1337.github.io/solid-octo-fiesta/)

## ✨ Возможности

- 📊 **4 торговые стратегии** (Momentum RSI, Mean Reversion, Gap Trading, MACD Crossover)
- 📈 **Интерактивные графики** с Chart.js
- 💾 **Загрузка своих данных** через CSV
- 🎯 **Сравнение стратегий** в реальном времени
- 📱 **Адаптивный дизайн** для мобильных устройств
- ⚡ **Быстро** - все работает локально в браузере
- 🆓 **Бесплатно** - никаких серверов не требуется

## 🚀 Как использовать

1. Откройте сайт
2. Выберите стратегии для тестирования
3. Настройте параметры риск-менеджмента
4. Нажмите "Запустить бэктест"
5. Анализируйте результаты в таблицах и графиках

## 📊 Demo данные

По умолчанию используются сгенерированные данные для демонстрации.

**Или загрузите свой CSV файл:**

```csv

2024-01-01,150.00,152.00,149.00,151.00,1000000
2024-01-02,151.00,153.00,150.00,152.50,1200000
...
```

## 🛠️ Технологии

- Чистый HTML/CSS/JavaScript
- Chart.js для графиков
- PapaParse для CSV
- GitHub Pages для хостинга
