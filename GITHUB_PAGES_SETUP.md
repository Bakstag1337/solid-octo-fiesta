# 🚀 Как включить GitHub Pages за 30 секунд

## Шаг 1: Перейти в настройки репозитория

1. Открыть https://github.com/Bakstag1337/solid-octo-fiesta
2. Кликнуть на вкладку **Settings** (⚙️ Настройки)

## Шаг 2: Включить GitHub Pages

1. В левом меню найти **Pages**
2. В разделе "Build and deployment":
   - **Source:** выбрать `Deploy from a branch`
   - **Branch:** выбрать `claude/backtesting-platform-daytrading-01DJkp8GuYBufZYHv9181NRr`
   - **Folder:** выбрать `/docs`
3. Нажать **Save**

## Шаг 3: Подождать 1-2 минуты

GitHub автоматически:
- Соберет сайт из папки `docs/`
- Опубликует его на GitHub Pages
- Покажет зеленую галочку когда готово

## Шаг 4: Открыть сайт

Ваш сайт будет доступен по адресу:

```
https://bakstag1337.github.io/solid-octo-fiesta/
```

## 🔧 Если что-то не работает

### Сайт не открывается (404)
- Подождите 2-3 минуты после включения Pages
- Проверьте что выбрана правильная ветка и папка `/docs`
- Обновите страницу с Ctrl+F5

### Ошибка при включении Pages
- Убедитесь что репозиторий публичный (или у вас GitHub Pro)
- Проверьте что папка `docs/` существует в выбранной ветке

### JavaScript не работает
- Откройте консоль браузера (F12) и проверьте ошибки
- Убедитесь что разрешены скрипты

## 🎯 Альтернатива: через Actions (автоматически)

GitHub Pages уже настроен через GitHub Actions:
- Файл `.github/workflows/pages.yml` автоматически деплоит сайт
- При каждом push в ветку автоматически обновляется сайт

Для использования через Actions:
1. Settings → Pages
2. Source: `GitHub Actions`
3. Workflow уже настроен - больше ничего не нужно!
